# 90-minute rehearsal

This is a pressure drill, not a miniature seven-hour day.

- **0–10:** read the brief, run both repos, write the problem contract.
- **10–25:** run a bounded read-only discovery fan-out, trace one request end to end,
  and ask one high-value chaperone question.
- **25–60:** build the smallest vertical slice and verify at the public seams.
- **60–70:** run a self-critique; fix the highest-risk defect only.
- **70–75:** synthesize the evidence and stop feature work unless correctness is broken.
- **75–80:** rehearse a five-minute demo.
- **80–85:** deliver the five-minute demo.
- **85–90:** answer questions and record the debrief.

Have another person or agent play one product chaperone and one engineering
chaperone. They answer only when you ask a precise question.
