# 90-minute rehearsal

This is a pressure drill, not a miniature seven-hour day.

- **0–10:** read the brief, run both repos, write the problem contract.
- **10–25:** trace one request end to end; ask one high-value chaperone question.
- **25–60:** build the smallest vertical slice and verify at the public seams.
- **60–72:** run a critic pass; fix the highest-risk defect only.
- **72–90:** render and deliver the demo. Stop implementation at minute 75 unless
  correctness is broken.

Have another person or agent play one product chaperone and one engineering
chaperone. They answer only when you ask a precise question.
