# Full-day rehearsal

Use the adaptive schedule in `OPERATING-BRIEF.md`. Protect at least 45 minutes for the
demo, but allow correctness work to continue if the main path is broken. Run a verbal
check-in at the midpoint and a green/yellow/red scope decision with roughly 90 minutes
remaining.

Take a real lunch break. The rehearsal tests judgment and collaboration, not just
typing endurance.
