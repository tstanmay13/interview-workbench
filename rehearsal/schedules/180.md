# 3-hour rehearsal

- **0–20:** orient, run the system, and establish the problem contract.
- **20–45:** map the cross-repo path and test the riskiest assumption.
- **45–125:** implement a vertical slice with checkpoint at minute 85.
- **125–145:** independent critique and focused correction.
- **145–180:** freeze features, render the evidence, rehearse questions, and demo.

Keep the central implementation in your main thread. Use at most two read-only
subagents for genuinely independent discovery or review tasks.
