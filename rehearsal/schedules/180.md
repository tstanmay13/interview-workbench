# 3-hour rehearsal

- **Before the timer:** give `.workbench/facilitator.md` to the human or agent playing
  the engineering chaperone without reading it yourself.
- **0–20:** context setting and simulated setup friction: begin from incomplete docs,
  surface the exact blocker, and ask for the official baseline only when warranted.
- **20–45:** map the cross-repo path and test the riskiest assumption with a bounded
  discovery wave.
- **45–125:** implement a vertical slice with checkpoint at minute 85.
- **85 checkpoint:** have the product chaperone give one piece of reviewer feedback;
  state how it changes scope before continuing.
- **125–145:** exercise explicit failure handling, run an independent critique, and make
  one focused correction.
- **145–160:** freeze features and render the evidence.
- **160–170:** deliver a ten-minute demo that includes the failure path.
- **170–180:** questions and structured self-critique.

Keep the central implementation in your main thread. Use at most two read-only
subagents for genuinely independent discovery or review tasks.
