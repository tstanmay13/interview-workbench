# Facilitator card: three-hour rehearsal

Do not show this card to the candidate before the timer starts. You are introducing one
bounded setup perturbation, not manufacturing an infrastructure disaster.

1. Start the case service with the wrong port: `PORT=4199 npm start`.
2. Tell the candidate only that both applications were believed to be ready.
3. Let them run the documented review-console path and collect evidence.
4. When they present the failing request, exact observed ports, attempts, and current
   theory, confirm that the supported API port is `4100`.
5. Ask them to choose and explain the cheapest safe recovery. Do not require a code
   change; restarting the service is valid.

After the baseline works, introduce one piece of reviewer feedback at the scheduled
midpoint. Keep it small enough that the candidate can either incorporate it or reject it
with a clear scope argument.
