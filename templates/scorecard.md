# Rehearsal scorecard

Score each dimension **0–3** with one specific piece of evidence. A total without
evidence is not useful.

| Dimension | 0 | 1 | 2 | 3 | Score | Evidence / improvement |
|---|---|---|---|---|---:|---|
| Outcome framing | No outcome | Vague task | Clear user outcome | Outcome drives scope |  |  |
| System understanding | Prompt-and-hope | Partial trace | End-to-end trace | Risks and boundaries explained |  |  |
| Agent leverage | Chaotic delegation | Some help, weak synthesis | Bounded useful tasks | Parallel work measurably sharpened main path |  |  |
| Verified delivery | No proof | Happy path only | Public seam tested | Failure and regression proof |  |  |
| Collaboration | Silent | Status only | Timely questions/check-ins | Feedback changes the work visibly |  |  |
| Demo and critique | Feature tour | Basic demo | Claim/evidence/limits | Crisp narrative plus prioritized self-critique |  |  |

## Debrief

- What decision created the most leverage?
- Where did I lose time, and what observable triggered it?
- What did a chaperone learn about me as a teammate?
- What would I do differently in the first 30 minutes next time?
- Which workflow step earned its cost? Which one should be removed?
